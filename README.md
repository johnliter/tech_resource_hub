# Cosmic Tech Hub 🚀

![Cosmic Tech Hub Screenshot](./screenshot.jpg)

A futuristic space-themed directory of technology resources, making it easier to find the best tech websites, blogs, and tools across various categories.

## Features ✨

- 🪐 Space-themed UI with animated elements
- 🔍 Instant search functionality
- 🏷️ Category filtering (News, Development, AI, Security, etc.)
- 📱 Fully responsive design
- 📌 Sticky footer with contact info
- ♻️ Easy to add new resources

## How to Add Resources

### Method 1: Submit via GitHub
1. Fork this repository
2. Edit the `script.js` file
3. Add your resource to the `resources` array following this format:
```javascript
{
    title: "Resource Name",
    description: "Brief description of what the resource offers",
    category: "category-name", // Choose from existing categories
    url: "https://example.com"
}
```
4. Create a pull request
